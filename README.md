# 📚 My Book Reader
### A WebApp for schools and students ✨

---

## 🌐 English

### 🎯 Features
- **Optimized for +300 pages** - Handles large PDFs without any problem 🚀
- **100% Offline** - No internet connection needed after first load 📄
- **No lagging** - Smooth scrolling and page transitions ⚡
- **Cross-browser compatible** - Works on Chrome, Firefox, Edge, Safari, and more 🌏
- **Zero installation** - Just open the file and start reading
- **Minimal design** - Clean interface focused on reading
- **Dark Mode** - Dark mode for best quality

### 📥 How to Get It
```bash
git clone https://github.com/AmirAliV88/My-Book-reader.git
```
Then double-click on `Page.html` to open it in your browser.

### 🛠️ Tech Stack
- HTML5 + CSS3 + JavaScript (Base of FrontEnd)
- PDF.js lib
