# 📚 My Books — کتاب‌خوان PDF و ویدیو پلیر آفلاین 🎬

> یک ابزار ساده، سریع و مینیمال برای مطالعه‌ی فایل‌های PDF و تماشای ویدیوها؛ بدون نصب، بدون تبلیغات و کاملاً آفلاین 🚀

اگر تا حالا هنگام باز کردن کتاب‌های سنگین یا فایل‌های ویدیویی طولانی در مرورگر با کندی، هنگ کردن یا طراحی‌های شلوغ مواجه شده‌اید، **My Books** برای شما ساخته شده است.  
این پروژه با تمرکز روی سرعت، سادگی و تجربه‌ی کاربری بهتر طراحی شده تا بتوانید فایل‌های خودتان را به‌راحتی در مرورگر اجرا کنید. ✨

---

## 🌟 ویژگی‌های اصلی

### 📖 PDF Reader — PDF خوان سریع و مینیمال

یک PDF خوان سبک و بهینه برای مطالعه‌ی کتاب‌ها و جزوه‌های حجیم.

#### امکانات:

- ⚡ بهینه‌شده برای کتاب‌های سنگین با بیش از **۳۰۰ صفحه**
- 🌙 طراحی کاملاً دارک برای مطالعه‌ی راحت‌تر در شب
- ☀️ مناسب برای استفاده در طول روز و محیط‌های مختلف
- 🎨 رابط کاربری مینیمال و بدون شلوغی
- 📄 نمایش روان صفحات PDF
- 🖨️ امکان پرینت گرفتن از هر صفحه
- 💻 اجرا مستقیم در مرورگر
- 📡 کاملاً آفلاین و بدون نیاز به اینترنت پس از دانلود پروژه

> برای مطالعه‌ی کتاب، جزوه، مقاله، مستندات فنی و فایل‌های آموزشی ساخته شده است. 📚

---

### 🎬 Video Player — ویدیو پلیر سریع و کاربردی

یک ویدیو پلیر ساده و سریع برای پخش فایل‌های ویدیویی شخصی شما.

#### امکانات:

- 🚀 اجرای سریع ویدیوهای طولانی و چندساعته
- ⚡ آماده‌سازی و رندر سریع فایل در همان لحظه
- 🌙 رابط کاربری کاملاً دارک و چشم‌نواز
- ⌨️ پشتیبانی از کیبورد برای کنترل سریع‌تر و واکنش بهتر
- 🎞️ مناسب برای فیلم، دوره‌های آموزشی، ویدیوهای ضبط‌شده و فایل‌های شخصی
- 💻 اجرا در مرورگر بدون نیاز به نصب نرم‌افزار اضافی
- 📡 کاملاً آفلاین و مناسب استفاده بدون اینترنت

## 📁 ساختار وب‌اپ‌ها

این پروژه شامل دو وب‌اپ مستقل است که هرکدام در یک فایل HTML جداگانه قرار دارند:

### 📚 `Book.html`

وب‌اپ مخصوص مطالعه و مدیریت فایل‌های PDF است.

با استفاده از این فایل می‌توانید:

- فایل‌های PDF خود را در مرورگر باز کنید
- کتاب‌های حجیم را با عملکرد بهینه مطالعه کنید
- از طراحی کاملاً دارک استفاده کنید
- صفحات موردنظر را پرینت بگیرید
- بدون نیاز به نصب نرم‌افزار جداگانه مطالعه کنید

### 🎬 `video.html`

وب‌اپ مخصوص پخش فایل‌های ویدیویی است.

امکانات این فایل شامل موارد زیر می‌شود:

- پخش ویدیوهای طولانی و چندساعته
- اجرای سریع فایل‌های ویدیویی در مرورگر
- رابط کاربری کاملاً دارک
- پشتیبانی از کیبورد برای کنترل سریع‌تر ویدیو
- استفاده‌ی آفلاین و بدون نیاز به نصب پلیر جداگانه

## 🚀 اجرای مستقیم وب‌اپ‌ها

بعد از کلون کردن پروژه، کافی است فایل موردنظر خود را در مرورگر باز کنید:

- برای استفاده از PDF خوان، فایل `Book.html` را اجرا کنید.
- برای استفاده از ویدیو پلیر، فایل `video.html` را اجرا کنید.

```bash
git clone https://github.com/AmirAliV88/My-Books.git
cd My-Books
```

سپس یکی از فایل‌های زیر را در مرورگر باز کنید:

```text
Book.html
video.html
```

به این ترتیب، هر دو ابزار بدون نیاز به نصب برنامه‌ی اضافی و به‌صورت کاملاً آفلاین در اختیار شما خواهند بود. 🌙📚🎬

## 🖥️ نحوه‌ی اجرا

### 1. کلون کردن پروژه

ابتدا پروژه را با دستور زیر دانلود کنید:

```bash
git clone https://github.com/AmirAliV88/My-Books.git
```

### 2. ورود به پوشه‌ی پروژه

```bash
cd My-Books
```

### 3. اجرای پروژه

فایل اصلی پروژه را در مرورگر خود باز کنید یا پروژه را با یک Local Server اجرا کنید.

برای مثال، اگر از VS Code استفاده می‌کنید، می‌توانید افزونه‌ی **Live Server** را نصب کرده و پروژه را اجرا کنید.

> پس از دانلود پروژه، برای استفاده از امکانات آن نیازی به اینترنت ندارید. 🌐❌
